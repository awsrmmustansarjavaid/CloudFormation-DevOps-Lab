If you want multiple lines in PowerShell

PowerShell uses the backtick ` for line continuation, not \.

aws ec2 describe-key-pairs `
  --query "KeyPairs[].KeyName" `
  --output table `
  --region us-east-1
Important

Your original command appears to have been entered like this:

--output table
--query "KeyPairs[].KeyName"
--region us-east-1
aws ec2 describe-key-pairs

That won't work because the aws ec2 describe-key-pairs command needs to come first.

For your CloudFormation lab, I recommend the one-line version:

aws ec2 describe-key-pairs --query "KeyPairs[].KeyName" --output table --region us-east-1

Then check that Lab-KeyPair appears in the output. If it does, that is the value you should use for your CloudFormation KeyPairName parameter.
