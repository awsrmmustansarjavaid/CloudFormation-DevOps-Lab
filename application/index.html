GitHub Actions

The Docker container can be tested with: 

curl http://localhost:8080

If the HTTP request succeeds, GitHub Actions can continue with the deployment pipeline.

Learning Objective

This application is intentionally simple so that the focus remains on learning Docker, Nginx, GitHub Actions, and AWS deployment concepts.

  • Build a Docker image.
  • Run the application inside a Docker container.
  • Serve static content with Nginx.
  • Test the container with curl.
  • Automate deployment using GitHub Actions.
